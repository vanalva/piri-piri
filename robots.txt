# Hand-authored. build-web.js copies src/static/** to the web root verbatim
# and leaves a hand-authored robots.txt alone rather than generating one, so
# this file is the live policy. Keep it in sync with src/static/sitemap.xml.
#
# Nothing here is blocked. The pages that must stay out of the index say so
# themselves with <meta name="robots" content="noindex"> — /legal,
# /carta-item, /juego-embed and the 4xx/5xx pages. That is deliberate: a
# path blocked in robots.txt is never fetched, so its noindex is never read,
# and Google can end up indexing the URL anyway from inbound links alone.
